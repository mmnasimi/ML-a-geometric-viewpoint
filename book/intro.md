# ML through the lens of representation

A 5-week course on machine learning that treats **representation**
as the central object of study, not the algorithm.

## The Central Question

> Given a phenomenon with structure and a task, an observation map,
> find a representation such that the structure relevant to the task
> is preserved or made explicit in the coordinates.

## Structure

Each session is a case study. We begin with a phenomenon, ask what
structure it has, and then ask which coordinates make that structure
visible to a model.

- **Session 00 — Why This Course Exists.** The projectile.
- **Session 01 — The Broken Toy.** The cantilever.
- **Session 02 — The Hidden Shape.** Coming.
- **Session 03 — ...**
