Section 1 — Generating the measurements¶

A cantilever beam has two strain gauges at the same cross-section, one on the top surface and one on the bottom. Two independent physical causes contribute to the readings:

  • Axial strain $\varepsilon_a$: tension or compression. Same sign on both surfaces.
  • Bending strain $\varepsilon_b$: bending. Opposite signs on top and bottom.

The raw readings are mixtures of the two, plus measurement noise.

In [2]:
rng = np.random.default_rng(0)
n = 300

# Two independent physical causes, each standard normal
axial   = rng.normal(0, 1.0, n)   # ε_a
bending = rng.normal(0, 1.0, n)   # ε_b

# Measurement noise (small)
noise = 0.05 * rng.normal(0, 1, (n, 2))

# Raw sensor readings — each mixes both causes
top    = axial + bending + noise[:, 0]   # ε_top
bottom = axial - bending + noise[:, 1]   # ε_bottom
X_raw  = np.c_[top, bottom]

print(f"Number of samples: {n}")

Each raw axis mixes the two physical causes. The boundary we care about — the level set where bending is zero — is the diagonal $\varepsilon_{\text{top}} = \varepsilon_{\text{bottom}}$.

A decision tree splits along one coordinate at a time. It cuts horizontally or vertically. It cannot cut along the diagonal.

The model's split directions and the physical direction differ.

This is the geometry we will exploit in Section 3.

Section 2 — The two representations¶

Mechanics tells us how to invert the mixture. The axial strain is the average of the two readings. The bending strain is their difference. Both are physical quantities with clear meaning.

The observations have not changed. The labels have not changed. Only the input coordinates have changed.

In the physical representation, the boundary is a single horizontal threshold at $\varepsilon_b = 0$. In the raw representation, it is the diagonal $\varepsilon_{\text{top}} = \varepsilon_{\text{bottom}}$.

That difference is the entire session.

The model is not stupid. The coordinates are stupid.

Section 4 — Do deeper trees fix this?¶

A natural objection: a shallow tree cannot fit the diagonal, but a deep tree can. This is true. And it is not the point.

A deep tree can approximate the diagonal arbitrarily well by adding more staircase steps. What it cannot do is extrapolate. Let us see why.

The deep tree looks much better inside the training region. It has more steps, and the boundary hugs the diagonal closely. If we only care about interpolation within the training range, the deep tree succeeds.

Now the failure. Outside the training range, the deep tree has no staircase steps. It simply extends the last box it saw. Let us ask it what happens at input points far outside the training data.

In [22]:
# Query points far outside the training region
# Format: (top, bottom, true class based on physics)
queries = [
    ( 6.0,  6.0, 0),   # bending = 0    → boundary, true class 0
    ( 6.0,  2.0, 1),   # bending = 2    → positive bending
    ( 2.0,  6.0, 0),   # bending = -2   → negative bending
    ( 6.0,  5.0, 1),   # bending = 0.5  → positive bending
    (-6.0, -5.0, 0),   # bending = -0.5 → negative bending
    ( 5.0, -1.0, 1),   # bending = 3    → positive bending
    (-1.0,  5.0, 0),   # bending = -3   → negative bending
]

print(f"{'Query (top, bottom)':22s}  {'True bending':>12s}  {'True class':>10s}  "
      f"{'Shallow pred':>12s}  {'Deep pred':>10s}")
print("-" * 80)
for top_q, bot_q, true_cls in queries:
    true_bend = (top_q - bot_q) / 2
    pred_shallow = tree_raw.predict([[top_q, bot_q]])[0]
    pred_deep    = tree_deep.predict([[top_q, bot_q]])[0]
    flag_shallow = '✓' if pred_shallow == true_cls else '✗'
    flag_deep    = '✓' if pred_deep == true_cls else '✗'
    print(f"({top_q:+5.1f}, {bot_q:+5.1f})         "
          f"{true_bend:+12.2f}  {true_cls:>10d}  "
          f"{pred_shallow:>10d} {flag_shallow}  "
          f"{pred_deep:>8d} {flag_deep}")

Read the last column carefully. The deep tree is confident everywhere. It has no way to signal that it has left the region where it was trained. It extends its last box indefinitely, and the prediction it returns is arbitrary.

This is the silent failure the cheap habit cannot see. Training accuracy was near 1.0. Cross-validation was high. And yet, one step outside the training distribution, the model is wrong with the same confidence as when it was right.

A deep tree can fit the diagonal. It cannot extrapolate it. The failure is representational, not algorithmic. The right coordinates remove the need for extrapolation because the boundary is no longer a diagonal — it is a threshold the model was trained on directly.

This is why the session is about representation, not model capacity.

Section 5 — Summary¶

The cantilever has shown the same root cause as the projectile, through a different mechanism.

  • The projectile's hypothesis class could not express the shape.
  • The cantilever's coordinates mixed the causes.

In both cases the fix was to change the representation. In both cases no amount of data or tuning could have saved the original setup. In both cases the right representation came from prior knowledge, not from the data.

The question we leave with: what happens when we do not know the physics?

This is the subject of Session 2.
